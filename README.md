# 그리움 퀘스트 — Frontend

> 떠난 사람이 그리워하는 대구·경북의 장소를, 남아 있는 사람과 여행자가 퀘스트로 대신 다녀와 안부를 전하는 서비스 (가칭)

2026 단디톤(멋쟁이사자처럼 14기 대구·경북 연합 해커톤) 출품작의 프론트엔드입니다.

## 화면

| ID | 화면 | 담당 |
|---|---|---|
| S1 | 로그인·회원가입 | 정형주 |
| S2 | 홈 (퀘스트 지도) | 남재민 |
| S3 | 그리움 등록 (AI 미리보기) | 정형주 |
| S4 | 퀘스트 상세 | 남재민 |
| S5 | 수행·인증 | 남재민 |
| S6 | 내 그리움 (안부 확인) | 정형주 |
| S7 | 내 기록 (스탬프 지도) | 정형주 |
